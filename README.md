# Jaivi's Diwali 3D Experience — Interactive edition

## What's included
- A personal opening greeting for Jaivi.
- A warm, brighter 3D Diwali entrance and decorated street.
- Six-scene cinematic journey: greeting, knock at the door, opening door, colorful street reveal, Jaivi-name rangoli, fireworks and a “Miss you, Jaivi” ending.
- Door knock animation and a swinging-open door.
- A custom ground-level rangoli with JAIVI written in the centre.
- Sweeping camera moves and captions to guide the story.
- Two stylized 3D friends sitting together to watch the fireworks.
- Floating sky lanterns and glowing diyas.
- Colorful 3D particle fireworks.
- At the ending, click/tap the sky to launch your own extra fireworks and make a wish.

## Files
- `index.html` — page structure.
- `style.css` — opening screen, captions and interactive prompt.
- `script.js` — Three.js scene, camera journey, characters, lanterns and fireworks.
- `assets/` — folders ready for extra custom assets.

## Run without npm
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Right-click `index.html` -> **Open with Live Server**.
4. Keep internet on because Three.js and GSAP load from public CDNs.

Alternative: run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.
